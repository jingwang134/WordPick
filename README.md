# 拾词 WordPick 🧠

> 在真实场景里拾取地道单词 —— 真实语料驱动的场景化英语学习应用

WordPick 是一套**纯前端、零依赖**的英语学习应用：从 YouTube 双语字幕语料中提炼真实表达，用「场景探索 + 看图学词 + 游戏化复习」的方式记住单词。打开浏览器即用，数据全部存本地。

## ✨ 核心特色

| 模块 | 说明 |
|---|---|
| 🌱 **词根词缀** | 30 个词根思维导图，248 词，词根字母红色高亮，单词按四级/六级/雅思/托福分级筛选 |
| 📚 **主题场景** | 雅思写作 10 大话题，123 词，每个词都带**词伙搭配 + 同义替换**（写作提分关键） |
| 🏙️ **场景词汇** | 28 个一级分类 × 113 个生活微场景，每场景 = 名词词块 + 动作短语 |
| 🗺️ **场景探索** | 一张真实场景大图 + 可点热点 → 延伸卡（怎么用/例句/相关词/贴士），相关词可跳转形成**词网** |
| 📷 **看图学词** | AI 生成的**写实照片**（每张角度道具不同），名词看图认词 + 动词"看图→提问→点一下看答案" |
| 🎬 **语料驱动** | 从 YouTube 双语字幕（SRT）提炼真实表达，**绝不手编**——语料就是唯一事实来源 |
| 📥 **语料提炼中心** | 拖入 .srt 文件，前端自动解析中英对照 + 高频词统计，点词看例句上下文 |
| 📥 **我的词库** | 导入自定义单词表、间隔重复复习（4 盒算法）、造句输出转积极词汇 |
| 🎴 **卡片工坊** | 小红书风格词汇卡片，4 种配色，一键下载 PNG |

## 🚀 快速开始

```bash
# 方式一：直接双击打开（部分浏览器限制本地文件加载需用方式二）
open index.html

# 方式二：本地服务器（推荐）
python -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

**零依赖、纯静态**：只需要一个浏览器，所有数据存 localStorage。

## 📂 项目结构

```
├── index.html              # 主应用（界面 + 逻辑）
├── data.js                 # 词根词缀 + 雅思主题 + 听力场景词库（30 词根 248 词 + 10 主题 123 词 + 16 场景 210 词）
├── life.js                 # 生活微场景（28 分类 113 场景，含 YouTube 语料提炼场景）
├── look.js                 # 看图学词数据（写实照片场景 + 名词/动词 + 场景探索热点词网）
├── map.js                  # 场景思维导图（DEMO × 5）
├── images.js               # 场景图片映射
├── images/                 # AI 生成的场景照片（写实风 JPG）
│   └── look/               # 看图学词专属照片（每张角度/道具不同）
├── corpus-wishlist.html    # YouTube 语料下载清单（28 分类 × 109 场景搜索词，可勾选进度）
├── parse_srt.py            # SRT 双语字幕解析工具（支持分类子文件夹，→ corpus/*.txt + summary.json）
├── analyze_corpus.py       # 词频 + 搭配分析工具（→ keywords.json）
└── compress_images.py      # 图片批量压缩工具（PNG → JPG，GitHub 上传前使用）
```

## 🎬 语料工作流（核心方法论）

```
下载 YouTube 双语字幕 (.srt)
    ↓ 放入 corpus-wishlist.html 对应的语料文件夹
parse_srt.py       → 解析出中英句对（corpus/*.txt + summary.json）
analyze_corpus.py  → 词频 + 搭配分析（keywords.json）
人工/AI 提炼      → 生成 nouns[] + actions[] → 入库（life4.js / look.js）
UI 标注            → 界面显示「🎬 真实语料」角标
```

> 原则：**每个场景先通读对应语料原文再提炼**，过滤机翻痕迹，只保留地道的真实表达。

## 🧪 场景探索交互

```
[一张真实场景大图]
   └─ ● 热点（呼吸动画圆点，带编号）
        └─ 点开 → 延伸卡
             ├─ 👆 怎么用（动词短语 + 缩略图）
             ├─ 💬 例句（语料原句）
             ├─ 🔁 相关词（点 chip 跳转其他热点 = 词网）
             └─ 💡 贴士（记忆要点）
```

## 🛠️ 技术说明

- **纯 HTML/CSS/JS**，无框架、无构建、无外部依赖
- 数据与界面分离：词库在 `data.js`，场景在 `life*.js`，照片场景在 `look.js`，加内容只改数据文件
- 学习记录 / 复习进度 / 下载清单进度 → localStorage
- 图片由 AI 生成（写实照片风），后续可替换为真实拍摄照片
